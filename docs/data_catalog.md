# Gold層 データカタログ

## 概要
Gold層は、分析やレポートに活用しやすいよう整理・構造化された、ビジネス向けのデータ層です。特定のビジネス指標を分析するための**ディメンションテーブル**と**ファクトテーブル**で構成されています。

---

### 1. **gold.dim_customers**
- **目的:** 人口統計情報および地理情報を付加した顧客の詳細情報を格納します。
- **カラム:**

| カラム名        | データ型     | 説明                                                                     |
| --------------- | ------------ | ------------------------------------------------------------------------ |
| customer_key    | VARCHAR(32)  | ディメンションテーブル内の各顧客レコードを一意に識別するサロゲートキー |
| customer_id     | NUMBER(38,0) | 各顧客に割り当てられた一意の数値識別子                                 |
| customer_number | VARCHAR(50)  | 顧客を表す英数字の識別子。追跡や参照に使用されます                     |
| first_name      | VARCHAR(50)  | システムに登録されている顧客の名                                       |
| last_name       | VARCHAR(50)  | 顧客の姓                                                               |
| country         | VARCHAR(50)  | 顧客の居住国（例: `Australia`）                                        |
| marital_status  | VARCHAR(50)  | 顧客の婚姻状況（例: `Married`、`Single`）                              |
| gender          | VARCHAR(50)  | 顧客の性別（例: `Male`、`Female`、`n/a`）                              |
| birthdate       | DATE         | 顧客の生年月日。YYYY-MM-DD形式（例: `1971-10-06`）                     |
| create_date     | DATE         | 顧客レコードがシステムに作成された日付                                 |

---

### 2. **gold.dim_products**
- **目的:** 製品およびその属性に関する情報を提供します。
- **カラム:**

| カラム名             | データ型     | 説明                                                                         |
| -------------------- | ------------ | ---------------------------------------------------------------------------- |
| product_key          | VARCHAR(32)  | 製品ディメンションテーブル内の各製品レコードを一意に識別するサロゲートキー |
| product_id           | NUMBER(38,0) | 社内での追跡や参照のために製品へ割り当てられた一意の識別子                 |
| product_number       | VARCHAR(50)  | 製品を表す構造化された英数字コード。分類や在庫管理によく使用されます       |
| product_name         | VARCHAR(50)  | 種類、色、サイズなどの主要な詳細情報を含む製品名                           |
| category_id          | VARCHAR(50)  | 製品の上位分類に紐づく、製品カテゴリーの一意の識別子                       |
| category             | VARCHAR(50)  | 関連製品をグループ化するための大分類（例: `Bikes`、`Components`）          |
| subcategory          | VARCHAR(50)  | 製品の種類など、カテゴリー内でのより詳細な分類                             |
| maintenance_required | VARCHAR(50)  | 製品にメンテナンスが必要かどうかを示します（例: `Yes`、`No`）              |
| cost                 | NUMBER(38,0) | 通貨単位で表した製品の原価または基本価格                                   |
| product_line         | VARCHAR(50)  | 製品が属する製品ラインまたはシリーズ（例: `Road`、`Mountain`）             |
| start_date           | DATE         | 製品の販売または利用が開始された日付                                       |

---

### 3. **gold.fact_sales**
- **目的:** 分析用の売上取引データを格納します。
- **カラム:**

| カラム名      | データ型     | 説明                                                                     |
| ------------- | ------------ | ------------------------------------------------------------------------ |
| order_number  | VARCHAR(50)  | 各受注を一意に識別する英数字の識別子（例: `SO54496`）                  |
| product_key   | VARCHAR(32)  | 受注を製品ディメンションテーブルに紐づけるサロゲートキー               |
| customer_key  | VARCHAR(32)  | 受注を顧客ディメンションテーブルに紐づけるサロゲートキー               |
| order_date    | DATE         | 注文が行われた日付                                                     |
| shipping_date | DATE         | 注文品が顧客へ出荷された日付                                           |
| due_date      | DATE         | 注文代金の支払期日                                                     |
| sales_amount  | NUMBER(38,0) | 注文明細の売上合計金額。通貨の最小単位を含まない整数値（例: `25`）     |
| quantity      | NUMBER(38,0) | 注文明細で注文された製品の数量（例: `1`）                              |
| price         | NUMBER(38,0) | 注文明細における製品の単価。通貨の最小単位を含まない整数値（例: `25`） |
